🎬 Image Sequence Support for Label Studio

This feature allows you to use JPEG/PNG image sequences directly with <VideoRectangle> without converting them to video files first. Perfect for packds format datasets.

Option 1: Array of Frame URLs

Use this when your task data contains an array of image URLs:

Labeling Config:

<View>
  <Video name="video" frameSequence="$frames" frameRate="30" />
  <VideoRectangle name="box" toName="video" />
  <Labels name="label" toName="video">
    <Label value="Person" />
    <Label value="Car" />
  </Labels>
</View>

Task Data (JSON):

{
  "frames": [
    "https://storage.example.com/episode_001/frame_000001.jpg",
    "https://storage.example.com/episode_001/frame_000002.jpg",
    "https://storage.example.com/episode_001/frame_000003.jpg",
    // ... more frames
  ]
}

Option 2: URL Pattern

Use this when frames follow a predictable naming pattern:

Labeling Config:

<View>
  <Video 
    name="video"
    frameSequence='{
      "type": "pattern",
      "pattern": "$baseUrl/frame_{frame}.jpg",
      "totalFrames": "$totalFrames",
      "padWidth": 6,
      "startFrame": 0
    }'
    frameRate="30"
  />
  <VideoRectangle name="box" toName="video" />
  <Labels name="label" toName="video">
    <Label value="Robot" />
    <Label value="Gripper" />
  </Labels>
</View>

Task Data (JSON):

{
  "baseUrl": "https://storage.example.com/packds/episode_001",
  "totalFrames": 1000
}

This generates URLs like: https://storage.example.com/packds/episode_001/frame_000000.jpg

Pattern Configuration Options

Option Description Default
pattern URL pattern with {frame} placeholder (required)
totalFrames Total number of frames (required)
padWidth Zero-pad frame numbers to this width 0 (no padding)
startFrame Starting frame number in filenames 0
✓ Benefits over converting to video:
  • Faster loading - Frames are loaded on-demand with smart preloading
  • No preprocessing - No need to merge JPEGs into MP4 files
  • Native packds support - Works directly with JPEG sequences
  • Memory efficient - Only caches nearby frames
Note: All standard <Video> features work with image sequences: play/pause, timeline scrubbing, frame stepping, zoom/pan, VideoRectangle annotations, etc.
